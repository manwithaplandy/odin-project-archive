## Looking back through the history

The original commits have been preserved without rewriting or squashing them. Every original branch is available as `history/<project>/<original-branch>`; original tags are named `<project>/<original-tag>`. These history branches retain the original repository layout. The `main` branch gathers the default-branch files into project folders.

For example, after cloning this repository:

```sh
git log origin/history/TOP-calculator/main
git show origin/history/TOP-calculator/main:README.md
```

`archive-manifest.json` records the original repository URLs, default-branch commits, and branch/tag references so the import can be verified.

This archive preserves source files and Git history. Issues, pull requests, repository settings, and GitHub Pages deployments remain associated with the original repositories. Each project's existing license and attribution files remain in its folder; this archive does not replace those licenses.
